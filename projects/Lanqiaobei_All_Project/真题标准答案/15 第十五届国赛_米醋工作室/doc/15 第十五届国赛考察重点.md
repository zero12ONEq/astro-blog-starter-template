# 串口解析

在我们的串口通信程序中，主要用到了两个函数来处理接收到的坐标指令或状态查询：

1. **`sscanf` 函数**：用于解析接收到的坐标数据。当串口接收到特定格式的数据，例如以 `(x,y)` 形式表示的目标位置坐标（其中 `x` 和 `y` 的值范围是 `0~999`），解析完成后将这些值直接赋予 `Target_Location` 数组，从而完成目标位置的设定。

2. **`strcmp` 函数**：用于精确匹配接收到的字符串指令。通过保证两个字符串完全一致，避免了将模糊匹配的内容误判为合法指令（例如，防止 `???` 被判断为 `?` 的问题）。这样可以使错误检测和响应更为合理化。

下面是程序的具体实现逻辑：

```c
if (strcmp(Uart_Rx_Buf, "#") == 0)
{
    // 当接收到 "#" 指令时，返回当前的位置坐标
    printf("(%u,%u)", Current_Location[0], Current_Location[1]);
}
// 查询设备状态
else if (strcmp(Uart_Rx_Buf, "?") == 0)
{
    // 返回当前设备的工作模式
    if (Work_Mode == 0)
        printf("Idle"); // 空闲状态
    else if (Work_Mode == 1)
        printf("Busy"); // 忙碌状态
    else if (Work_Mode == 2)
        printf("Wait"); // 等待状态
}
// 设置目标位置
else if (Uart_Rx_Buf[0] == '(' && Uart_Rx_Buf[Uart_Rx_Index - 1] == ')')
{
    // 检查当前设备是否处于空闲状态
    if (Work_Mode == 0)
    {
        // 使用 sscanf 从接收到的字符串中提取坐标值并赋值给 Target_Location
        sscanf(Uart_Rx_Buf, "(%u,%u)", &Target_Location[0], &Target_Location[1]);
        Target_Flag = 1; // 标记有新的目标位置指令
        printf("Got it"); // 响应：接受成功
    }
    else
    {
        printf("Busy"); // 当前非空闲状态，无法接受新指令
    }
}
else
{
    // 如果接收到的指令格式不符合要求则返回错误信息
    printf("ERROR");
}
```

## 工作逻辑详解：

1. **读取当前位置**  
   当接收到 `"#"` 指令时，设备会输出目前的坐标，其中，`Current_Location` 是一个表示当前位置的数组，例如 `(123,456)`。

2. **查询设备状态**  
   当接收到 `"?"` 指令时，设备会返回当前的工作模式状态：
   - `"Idle"` 表示处于空闲状态，可以接收新的目标位置指令；
   - `"Busy"` 表示设备正在执行任务中，无法接收新指令；
   - `"Wait"` 表示设备处于等待某种操作的状态。

3. **接收目标位置数据**  
   - 接收到的数据需要满足 `(x,y)` 的格式。
   - 只有当设备为空闲状态（`Work_Mode == 0`）时，数据解析才会生效：
     - `Target_Location` 会被更新为解析后的坐标值；
     - 将 `Target_Flag` 设置为 `1`，以标记目标位置已经被设定成功。
   - 如果设备不处于空闲状态，则返回 `"Busy"`，提示无法接受新的位置信息。

4. **错误处理**  
   如果接收到的数据不符合预期的格式或指令类型，例如未知字符或无效指令，则返回 `"ERROR"`，明确表示指令无法识别或不被支持。



# 运动控制部分

## ** 设定与假设**

### **目标**
我们希望通过算法让机器人从当前位置（$(x_1, y_1)$）沿着直线运动，最终到达目标位置（$(x_2, y_2)$）。运动过程中需要保持速度 $v$ 恒定，并确保机器人每控制周期中的位移在方向向量的引导下逼近目标点。

### **数学模型的本质**
机器人在二维平面上的运动可以抽象为按照指定方向与速度的**有向直线运动**，其本质是二维空间中**一阶动力学系统**的一种离散化实现。

## ** 几何向量与解析几何的说明**

### **位移向量**
在二维欧几里得空间中，从当前位置 $(x_1, y_1)$ 到目标位置 $(x_2, y_2)$ 的位移向量为：
$
\boldsymbol{\Delta} = (Δx, Δy) = (x_2 - x_1, y_2 - y_1)
$
对应的是从 $(x_1, y_1)$ 指向 $(x_2, y_2)$ 的方向。

### **距离的数学表示**
当前位置与目标点之间的距离是位移向量模长（L2范数）：
$
d = \|\boldsymbol{\Delta}\| = \sqrt{Δx^2 + Δy^2} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}.
$
> **解释：** 这是机器人与目标点之间的直线距离，用来衡量机器人与目标点的接近程度。

### **单位方向向量**
为了计算运动方向，需对位移向量 $\boldsymbol{\Delta}$ 归一化，得到对应的**单位方向向量**：
$
\boldsymbol{u} = (u_x, u_y) = \left( \frac{Δx}{d}, \frac{Δy}{d} \right) = \left( \frac{x_2 - x_1}{\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}}, \frac{y_2 - y_1}{\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}} \right).
$
单位向量的模为 $1$，保证机器人运动的方向与目标点方向一致，同时将运动引导到直线上。

### **运动步长与方向的结合**
机器人每周期沿单位向量 $\boldsymbol{u}$ 运动的距离为 $\text{step}$：
$
\Delta_{\text{step}} = (Δx_{\text{step}}, Δy_{\text{step}}) = \boldsymbol{u} \cdot \text{step} = \left( \frac{Δx}{d} \cdot \text{step}, \, \frac{Δy}{d} \cdot \text{step} \right)
$
由于单位向量的比例关系， $\Delta x_{\text{step}}$ 和 $\Delta y_{\text{step}}$ 确保了 $x$ 和 $y$ 方向上的移动是均匀分布的。



## **运动学的数学解释：离散时间动力学系统**

### 理解离散更新公式：

机器人的位置是每个微小时间间隔（控制周期）内增量更新的结果。这当中每周期的运动步长由：
$
\text{step} = v \cdot dt
$
控制，表示机器人在 $[t, t+\Delta t]$ 的时间区间内沿方向向量移动的距离。

在离散动力学系统中，每周期的更新公式为：
$
x_{n+1} = x_n + \frac{x_2 - x_n}{d} \cdot v \cdot dt, \quad y_{n+1} = y_n + \frac{y_2 - y_n}{d} \cdot v \cdot dt
$
这实际上是在模拟连续动力学系统的离散版本。连续系统可以表示为：

### 连续模型：
如果使用微分方程描述机器人运动，其动力学模型为：
$
\frac{dx(t)}{dt} = v \cdot \frac{x_2 - x(t)}{\sqrt{(x_2 - x(t))^2 + (y_2 - y(t))^2}}
$
$
\frac{dy(t)}{dt} = v \cdot \frac{y_2 - y(t)}{\sqrt{(x_2 - x(t))^2 + (y_2 - y(t))^2}}
$

该方程利用**方向向量**控制二维运动轨迹，$\frac{dx}{dt}$ 和 $\frac{dy}{dt}$ 是 $x$ 和 $y$ 方向的速度分量，由目标位置动态引导现位置。

### 离散化公式推导：
为了简化实现，将其离散为每周期更新：
$
\Delta x_n = v \cdot \Delta t \cdot \frac{x_2 - x_n}{d}, \quad \Delta y_n = v \cdot \Delta t \cdot \frac{y_2 - y_n}{d}
$
$
x_{n+1} = x_n + \Delta x_n, \quad y_{n+1} = y_n + \Delta y_n
$
从而得到运动公式在离散时间下的形式。最终通过有限时间步长 $dt$ 离散解决控制问题。



## **边界条件与收敛性**

### **停止准则 (边界条件)**
系统需要判断是否已经足够接近目标点，避免过冲或超调。当剩余距离小于本周期步长时：
$
\text{if } d_n \leq v \cdot dt,
$
则直接置当前位置为目标点，停止运动，避免发生误差累积。

### **收敛分析**
对于二维离散动力学系统，每周期的运动步长总是随着距离 $d_n$ 缩短。例如：
$
d_{n+1} = d_n - \text{step} = d_n - v \cdot dt
$
简单证明表明，位移 $d_n$ 是单调递减的，并最终收敛到 0。因此，机器人在有限时间后一定会到达目标点，或者以精度 $\leq v \cdot dt$ 逼近目标点。

## **总结**

### **几何意义**
- 位移向量描述了机器人从当前位置到目标位置的方向和距离。
- 单位方向向量用于归一化位移方向，使得机器人沿直线运动。
- 每个周期增加的步长保证位置是向目标点单方向逼近的。

### **运动学意义**
- 系统遵循一阶动力学模型 $\dot{x}, \dot{y}$ 描述每方向上的速度。
- 离散更新公式模拟了连续微分运动，保证运动轨迹逼近连续解。

### **收敛性与终止条件**
- 随着时间推进，机器人不断靠近目标点，位移 $\|\boldsymbol{\Delta}\|$ 单调递减，并在有限时间内趋近于零。
- 终止条件保证了数值精确性，避免离散误差积累。

从数学角度，代码其实是对一个连续动力学过程的离散实现，其结果是逼近理论上的连续解，同时保证了轨迹的平滑性和速度的恒定性。
