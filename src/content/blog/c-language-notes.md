```c
#include <stdio.h>
```

### 3-2 注释

注释用法为截图加空代码块。（原图示，见飞书）

### 3-3 变量

（本节在飞书中多为截图讲解；概念并入下方常量与嵌入式视角。）

### 3-4-1 字面常量

- 整型常量：`123`
- 实型常量：`12.12`
- 字符型常量：`'a'`（单个字母、数字、英文符号、转义字符）
- 字符串常量：`"英雄"`

### 3-4-2 用 const 修饰常量

`const` 修饰后常量值不能改。好处是只改定义那一行。

```c
const int winWidth = 1080;
const int winHeight = 720;
```

常见错误：`error C2166` 左值指定 const 对象；`E0137` 表达式必须是可修改的左值。常量定义后未使用是合法的。可修饰 `int` / `float` / `char` / `double`。

### 3-4-3 用 #define 来修饰常量

格式：`#define 常量名 值`，结尾**没有分号**。有运算符要加括号：`#define x (1+2)`，否则 `x*x` 会按宏替换出错。

### 3-5 关键字

VS2022 里紫色或深蓝色标注，如 `for`、`int`、`return`。关键字表「不用记」。（截图见飞书）

### 3-6 标识符

- 由字母、数字、下划线组成
- 不能以数字开头
- 大小写敏感
- 不能是关键字
- 名字要能看懂含义

### 嵌入式 C 语言视角（以 STM32 的 ARM 架构为例）

1. `int a;` 是编译器在 RAM 开辟 4 字节
2. `a=1;` 时 AGU 生成地址，总线矩阵译码并片选 RAM，CPU 写入。译码相当于解引用
3. `int a=1;` 是定义加赋值
4. `const` / `#define` 常量写在 FLASH，同样经 AGU 和总线矩阵片选
5. 软件上的内存空间在硬件上是晶体管，1 个晶体管存 1 bit，高电平 1、低电平 0
6. `printf("今天的温度是%d 摄氏度", a);` 双引号是格式，`a` 对应 `%d`

## 4. 数据类型

### 4-1 / 4-2 数据类型初识与整型

（表格与例题多为截图，见飞书；下面从 sizeof / unsigned 起为完整文字。）

### 4-3 sizeof 的应用

`short` / `int` / `long` / `long long` 用 `%zu` 和 `sizeof(类型)` 打印所占字节。

### 4-4 unsigned 的应用

`unsigned short` 范围 \([0, 2^{16}-1]\) 即 0–65535（环理论）。`unsigned short a=-1` 输出 65535。占位符：`%hu` `%u` `%lu` `%llu`。

### 4-5 实型 / 浮点型

比赛尽量不用 `float`（精度不够）。`%.7f` / `%.7lf`。`.6` 和 `6.` 合法。科学计数法 `%e`。不能 `unsigned float`。需要 `#include <float.h>` 看 `FLT_MIN` / `MAX`、`DBL_MIN` / `MAX`。默认 `%f` 输出 6 位小数。

### 4-6 字符型

`%c` 输出字符，`%d` 看 ASCII。`sizeof(char)` 为 1。不要 `sizeof(a1)` 或 `sizeof('y')`——`sizeof` 会先把字符变成整型 ASCII 再测，得到 4 字节。`char` 范围 \([-128,127]\)，`char b1=128` 输出 -128（环理论）。

### 4-7 转义字符

`\"`、`\\`、`\t`、`\0`、`\n`。

### 4-8 字符串初识

`char a1[100]="日拱一卒";` 与 `char b1[]="内外兼修";`。

- `sizeof(a1)=100`（人为开辟）
- `sizeof(b1)=9`（4 个汉字 ×2 + `\0`，在该笔记环境的宽度假设下）

`c1[5]` 读字符，可改。结尾 `\0` 的 ASCII 是 0。

### 4-9-1 整数的输入

`scanf` 报 C4996：改 `scanf_s`，或文件开头 `#define _CRT_SECURE_NO_WARNINGS`。Ctrl+Alt+O 打开输出栏。

```c
int a;
scanf("%d",&a);
```

两个整数 `"%d%d"` 不要逗号。`%hd` `%ld` `%lld` 对应 short / long / long long。

### 4-9-2 浮点数的输入

输入类型不匹配时 `scanf` 不接收：有初值显示初值，否则乱码。

### 4-9-3 字符型的输入

`scanf_s` 读字符要多一个缓冲区大小参数，否则永远得到 `?`。

空格也是字符，连续 `%c` 会把空格读进去。正确做法见字符串输入。

`getchar` 同样把空格当字符；`putchar` 常与 `getchar` 连用。

### 4-9-4 字符串的输入

```c
scanf_s("%s", str, 100);
```

`%s` 把空格、制表符、换行当结束。含空格用 `fgets` 或 `gets_s`。

```c
fgets(str, sizeof(str), stdin);
str[strcspn(str, "\n")] = '\0';
```

用字符串读入再取 `str[0]` 可避开字符输入的坑。

### 嵌入式 c 语言视角（数据类型、volatile、进制、原码反码补码）

常用 `uint8_t` / `uint16_t` / `uint32_t` / `uint64_t` / `char` 及占位符。16 进制 `"0x%x"`。

`char` 在 SRAM 开 1 字节 = 8 个晶体管，signed 时最高位是符号。

`volatile` 防止「初始化后未使用」被编译器优化掉：`volatile int a=2;`

进制：满 n 进 1。八进制 `0` 前缀，一位用 3 bit；十六进制 `0x`，一位用 4 bit。

整数以补码存储。`1+(-1)` 的补码相加为 0。

`signed char c=0x81` → 补码 `1000 0001` → 原码对应 -127；无符号 char 则是 129。

小类型赋给大类型正常；大类型赋给小类型只留低 8 位。

多字节如 `int a=0x12345678` 的字节序见截图（见飞书）。浮点存储「不重要，以后补」。

## 5. 运算符和表达式

### 5-1 加减乘除、取余、字符加减

**四则：** `a/b` 整数除法只得商。大数要注意占位符。（浮点四则截图见飞书）

**取余：** 被除数和除数都必须是整数。结果正负只由被除数决定。与除法对比：取余得余数且只能整数；除法得商，正负由两者共同决定。

**字符加减：** `'Y'+1` 用 `%c` 得到相邻字符，用 `%d` 得到 ASCII。

小写转大写：`x = ch-'a'; y='A'+x;`。大写转小写同理。

### 5-2 递增递减

单独一条语句时 `i++` 与 `++i` 相同。

- `c=a++` 先用后加
- `d=++b` 先加后用

自减同理。`for` 里 `++i` 比 `i++` 效率略高，效果一样。

### 5-3 赋值运算符

写法从左往右，读法从右往左：`a=a+b` 读作把 `a+b` 赋给 `a`。

复合赋值 `+=` `-=` `*=` `/=` `%=` 是缩短写法。

### 5-4 关系运算符

`==` `!=` `>` `>=` `<` `<=`，成立输出 1，否则 0。

### 5-5 逻辑运算符

- `&&`：两边都非 0 才为 1
- `||`：一边非 0 就为 1
- `!`：非 0 变 0，0 变 1

不能写 `-10<x<10` 这种连续比较：计算机先算左边得到 0/1 再和右边比。

**短路：** 左边已能决定结果时不算右边。

### 5-6 逗号运算符

分隔定义：`int a=1,b=2,c=3;`。

`printf("%d", (a++, ++b, --c));` 只输出最后一个表达式的值。

交换变量：`r=a, a=b, b=r;`

### 5-7 位运算（与或异或取反左右移）

二进制字面量 `0b1110`。

- **位与 `&`：** 和 1 保留本身，和 0 变 0。应用：奇偶（`n&1`）、取低 4 位、把末尾连续 1 变 0
- **位或 `|`：** 有 1 则 1。应用：把某位置 1；置 0 用 `(x|mask)-mask` 这类写法（笔记里的演示）
- **异或 `^`：** 相同为 0，不同为 1，和 0 异或得本身，满足交换律结合律。应用：标记位取反、不用第三变量交换
- **按位取反 `~`：** 用 -1 解释补码；求相反数见笔记 2-3（截图见飞书）
- **左移 `<<`：** `x<<y` 等于 \(x\cdot 2^y\)，`1<<y` 是 2 的 y 次。负数左移、移负数位不合法。用来生成标记位再与 `&` `|` `^` 配合
- **右移 `>>`：** `x>>y` 约等于 \(x/2^y\)。移负数位不合法。应用：去掉低 k 位

### 5-8 表达式与优先级

表达式由运算符和操作数组成。常量本身也是表达式。

赋值右结合：`a=b=c` 即 `a=(b=c)`。加法左结合。

`(a==0)&&(b==0)` 与 `!a&&!b` 等价。一元运算符优先于二元。

规则：

1. 小括号最高
2. 一元 > 二元 > 三元（唯一三元是 `?:`，if 之后再讲）
3. 算术 > 关系 > 位 > 逻辑
4. `!` > `&&` > `||`
5. 逗号最低，赋值次之

### 6 控制流（提纲）

if 的难度取决于表达式是否学透。覆盖：语句、控制结构、if / else / else if / 嵌套 if、条件运算符、switch。

**switch 细节：** 括号里只能是整型或字符型；case 必须是常量且不能重复；break 可省略；default 处理其余情况。

循环：while、do while、for、死循环。跳转：break、continue、goto（能跳转但可读性差，可用其他语法代替）。

### 7 数组（提纲）

定义、初始化、元素访问、遍历、进制转换、二维数组（定义、初始化、访问、遍历、求最大值）。

### 8 函数（提纲）

函数是把常用代码封装起来减少重复。大程序由模块组成。已学过很多库函数。声明写在前面，方便别人看结构和功能模块。

### 9 指针（提纲）

指针是内存地址，如 `0x0000009B754FFA34`，变量 `p` 存这串地址。解引用可读写。还覆盖：运算、址传递、返回指针、多返回值、数组参数退化、空 / 野 / 悬空指针、void 指针、二级指针、指针常量 / 常量指针、指针数组与数组指针、指针函数与函数指针。

### 10 字符串（提纲）

字符数组与字符串；`fgets` + `str[strcspn(str,"\n")]='\0'`；`strlen` / `strcat` / `strcpy` / `strcmp`。`strcmp` 逐字符比 ASCII，全相同返回 0，前者小返回 -1，前者大返回 1。

### 11 结构体（提纲）

四种定义（含 typedef）、结构体数组、结构体指针、嵌套、作为函数参数。

### 12 联合体（提纲）

一种数据可能有多种类型时使用，例如货币可以是 `99999`、`99999.00` 或 `"99,999"`。成员共用一块内存。

### 13 枚举（提纲）

`const int MY_FAV_LAN=3` 看不出 3 的含义。枚举是一组离散命名常量，默认从 0 递增；给某一项赋值后下一项接着加。用于可读性（STOP / RUN）和集中维护常量。

### 14 动态内存（提纲）

`malloc`、`calloc`、`realloc`、`free`。内存四区：代码区、全局区（全局变量、静态局部 / 全局、字符串字面量、各类常量）、栈区（非静态局部变量和参数）、堆区。

### 15 文件（提纲）

本章：`fopen` 打开，`fgetc` / `fgets` / `fread` 读，`fputc` / `fputs` / `fwrite` 写，`fclose` 关闭。读是输入流（文件→程序），写是输出流（程序→文件）。随机读写：`fseek`、`ftell`、`rewind`（把文件指针重置到开头）。
