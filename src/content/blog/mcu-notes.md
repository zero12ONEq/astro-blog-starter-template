## 第一章 注意事项和必备技能

注意事项和必备技能同 STM32，详见 STM32 标准库开发指南。

## 第二章 选型

分类命名处有视频和截图。文字要点：

1. STC 是品牌名
2. 89 是系列名，12T 和 6T 的 8051 都用这个系列名

**机器周期：**

- 12T：1 个机器周期 = 12 个振荡周期
- 6T：1 个机器周期 = 6 个振荡周期

相同晶振下 6T 速度是 12T 的 2 倍。12 MHz 时，12T 机器周期为 1 μs，6T 为 0.5 μs。STC89C51XX 可在 6T / 12T 间切换。

批号例：`1325` 表示 2013 年第 25 周生产。

**封装：**

- 直插 DIP / PLCC：插座焊到板上，芯片插入。1 号脚是标记圆点所对引脚，逆时针编号。
- 贴片：四周有脚为 QFP（TQFP 等）；两侧有脚为 SOP（SSOP 等）。
- QFN 扁平无引脚；BGA 球栅阵列。

（分类命名视频与截图见飞书）

## 第三章 内部结构与总线架构

最中间是 CPU，经总线连接 FLASH、RAM、UART、IIC、GPIO。GPIO 寄存器配置引脚输入输出。

51 由 CPU 经数据总线、地址总线、控制总线连接外设：

- **地址总线**：寻址存储区 / 寄存器
- **数据总线**：读写 FLASH（常量、代码）、SRAM（变量 / 堆 / 栈）和外设寄存器
- **控制总线**：传 RD、WR、PSEN 等，协调读写时序

## 第四章 LED（西风 AT89C52）

LED 一端接 VCC（3.3 V），另一端接引脚。引脚输出低电平（往寄存器写 0）灯亮。P1 控制 DB1–DB8。

- **点灯法 1**：往 P1 写 `1010 1010`
- **点灯法 2**：分别往 P1 的各位写 0 / 1。例：D1 D2 D4 D6 D8 灭，其余亮
- **频闪**：D1 亮 100 ms 再灭 100 ms。延时函数来自 STC-ISP。主函数执行完一行后停 100 ms，维持上一行的灯状态

自定义微秒级延时：先在 STC-ISP 生成 1 ms 函数。若生成代码里有 `_nop_` 直接删掉，否则报错。

```c
/*延时1ms的函数*/
void Delay1ms()                //@12.000MHz
{
        unsigned char i, j;
        i = 2;
        j = 239;
        do
        {
                while (--j);
        } while (--i);
}
```

不用 `unsigned char` 以外的宽类型时要注意：它只能表示 0–255。不能用 `uint8_t`，因为 `REGX52.H` 没包含。

**流水灯：** D1–D8 依次点亮。笨办法是 `while` 里逐个写 `P1_x`。更好是 `intrins.h` 的 `_crol_`（循环左移）和 `_cror_`（循环右移）。（完整代码与现象为截图，见飞书）

## 第四章 IO 内部结构（郭天祥 STC89C53RC）

P1 / P2 / P3 为准双向口，默认弱上拉，高电平电流很弱。

- **输出**：锁存器写 1，下管断开，引脚接 VCC 为高；写 0，下管导通，引脚接 GND 为低
- **输入**：必须先写 1 让下管断开，弱上拉很容易被外部电平改变

P0 上电为开漏，无内部上拉，要外接上拉。输入同样先写 1，外部电平经输入缓冲（滤波）读入。

（IO 内部结构图示见飞书）

## 第六章 数码管

共阴极：高电平点亮，低电平熄灭。郭天祥板是三位连在一起。（显示 1 的接法见飞书）

原理图要点：先用 P0 往位锁存器某一位写 0 选中该管（接地），再往段锁存器写段码。位锁存器和段锁存器共用 P0_0–P0_7，**先位后段**。

- **实验 1**：第一个数码管显示 0。声明位码段码，`main` 外写 `Seg_Disp`，`while` 里 `Seg_Disp(0,0)`
- 不能连续 `Seg_Disp(0,0); Seg_Disp(1,1);`——后一次覆盖前一次，因为都用 P0。多个同时显示必须用定时器动态扫描
- **实验 2**：定时器让 6 个数码管依次显示 0–5。从 STC-ISP 复制定时器，加上 `ET0=1`、`EA=1`。每 1 ms 进中断，先恢复初值，`Seg_Pos` 和 `Seg_Number` 在 0–5 循环。1 ms 显示第 1 位 0，下一毫秒第 2 位 1，6 ms 一轮，肉眼同时看到 0–5

## 第七章 key / seg / led / 定时器 / 中断综合

数码管要用定时器减速（如 500 ms 一次）。`while` 太快时，传感器上一次数据还没处理完又来新数据，会覆盖出错。

按键也要减速，例如每 10 ms 处理一次，跳过按下时的电平抖动。

## 蓝桥杯外设专题

### 添加芯片信息

### LED 与 74HC573 / HC138

D0–D7 对应 P00–P07。二极管一端 5 V，另一端经 74HC573 接到 P00–P07。

**RS 锁存器：** R=1 S=0 输出 0；R=0 S=1 输出 1；R=S=0 关闭。不讨论 R=S=1。改进后 E=0 关闭，E=1 时 D 决定输出。

**74HC573：** LE=1 时 Dn 直通 Qn；LE=0 时 Q 保持。蓝桥杯原理图里 Y4C 就是 LED 那片的 LE。WR 接 GND 恒为 0，Y4C 为异或再取反，所以只要 Y4 输出 0，Y4C 就为 1。

**74HC138：** CBA 二进制选中 Yn 输出低电平。Y4 低电平需要 P27=1, P26=0, P25=0。

使能：`P2=(P2&0x1f)|0x80`，然后关闭 `P2=P2&0x1f`。

### init 上电关闭所有外设

1. 关 LED：P0=`0xff`，打开 Y4C 锁存器，再关掉
2. 关继电器、电机、蜂鸣器。U10 内部取反
   - 蜂鸣器关需要 N_BUZZ=1，即 P06=0
   - 继电器 N_RELAY=1 即 P04=0
   - 电机 N_MOTOR=1 即 P05=0
   - 所以 P0 写 `0x00`
   - Y5C 打开该锁存器：要 Y5 低电平，CBA=101，即 P27=1 P26=0 P25=1，`(P2&0x1f)|0xa0`，然后再 `P2=P2&0x1f` 关掉

（`init.c` / `init.h` / `led.c` / `led.h` 完整源码为截图，见飞书）

### DS18B20

三脚：VCC 5 V、GND、数据线 P14。温度以 16 位补码存储。

- `+25.0625` 的补码 `0000 0001 1001 0001`：高 5 位 0 为正，低 4 位是小数 \(2^{-4}=0.0625\)，中间 `001 1001`=25
- `-10.125` 的补码 `1111 1111 0101 1110`：减一再符号位不变、其余取反得原码，高 5 位为负，小数 0.125，整数 10

换算：原始值当整数再乘 0.0625，等价于除以 16。`+25.0625` → `401/16`。精度降低时低位被强制为 0（12 位 0.0625 ℃，11 位 0.125 ℃，10 位 0.25 ℃，9 位 0.5 ℃）。

步骤：初始化（延时参数 12 表示 \(12\times12=144\)；返回 bit，0 成功 1 失败）、写、读、ROM 命令（跳过 ROM 写 `0xCC`）、功能命令。

写一个字节：循环 8 次，先拉低，约 1 μs 后把该位放到 DQ，保持约 60 μs，释放，数据右移。

```c
void Config_Temper(unsigned char dat)
{       init_ds18b20();
        Write_DS18B20(0xcc);
        Write_DS18B20(0x4e);
        Write_DS18B20(0x7f);
        Write_DS18B20(0x00);
        Write_DS18B20(dat);
        init_ds18b20();
}
```

「从 DS18B20 读」一节主要是截图（见飞书）。题目解答见《51 单片机习题汇总》的《DS18B20 温度采集器》。

### PCF8591

蓝桥杯主要考 AD / DA。A0 A1 A2 接地。SCL=P20，SDA=P21。光敏电阻 AIN1，滑动变阻器 AIN3。

地址最后一位 0 表示主机写，1 表示主机读。常用 4 路单端输入（D5 D4 = 00）。

控制字节：D7 固定 0；D6 模拟输出使能；D3 保留；D2 自动增益；D1 D0 通道 0–3。

谁控制 SCL 谁是主机。数据只在 SCL 为高时有效。

- ACK：SCL 高时把 SDA 拉低
- NACK：SCL 高时释放 SDA，上拉为高
- 发送：先 SCL 低，准备 SDA，再 SCL 高。字节从 D7 到 D0。主机接收时先放在 D0 再左移

**AD：** 读到的是上一次转换结果。addr `0x40` 外部输入，`0x41` 光敏，`0x42` 差分，`0x43` 滑动变阻器。0–5 V 对应 0–255。写地址 `0x90`，读地址 `0x91`。

**DA：** 控制字节 `0x41`（D6=1 允许模拟输出），数字写入 DAC，用万用表量 D/A 脚。

起始位、应答、收发字节的底层官方会给。

### AT24C02

掉电不丢。A0 A1 A2（有的图写作 A3）和 WP 接地。写地址 `0xA0`，读地址 `0xA1`。

两种写：字节写和页写。比赛底层按页写。第一个参数一般是数组名（首元素地址）。

两种读：读任意地址，或读一整页。

简单应用：模式 0 显示 `dat[]={30,60}`，S19 / S18 各加 10，S17 存入 EEPROM，断电再上电应显示保存值。模式 1 用三位显示 `unsigned char a`（初值 200），S16 减 10，S15 加 10，S14 保存。`unsigned int` 的写入「未来再补」。

测试时先注释 `EEPROM_Read`，改值，仿真断电，再取消注释编译，频率要设 12 MHz。（代码为截图，见飞书）

### 数码管小数点技巧

`Seg_Buf` 里写大于 20 的数表示带小数点。

```c
pdata unsigned char Seg_Buf[8]={16,16,16,16,16,16,16,16};
idata unsigned char Seg_Pos=0;
void Timer1Init(void)                //1毫秒@12.000MHz
{
        AUXR &= 0xBF;
        TMOD &= 0x0F;
        TL1 = 0x18;
        TH1 = 0xFC;
        TF1 = 0;
        TR1 = 1;
        ET1 = 1;
        EA = 1;
}
void Timer1_Isr(void) interrupt 3
{
        if(Seg_Buf[Seg_Pos]>20)
                Seg_Disp(Seg_Pos,Seg_Buf[Seg_Pos]-',',1);
        else
                Seg_Disp(Seg_Pos,Seg_Buf[Seg_Pos],0);
        Seg_Pos=(++Seg_Pos)%8;
}
```

例：46（44+2）显示 `2.`，49（44+5）显示 `5.`。

### DS1302

可操作引脚：SDA、RST(CE)、SCK。

```c
#include "intrins.h"
sbit SDA=P2^3;
sbit RST=P1^3;
sbit SCK=P1^7;
```

先发 8 位命令（读则最后一位为 1，写为 0），再按 BCD 或十进制读写。写之前要关掉时钟振荡（CH 位置 1），否则边计时边写会对不上。顺序是时、分、秒；读也是先时再分再秒。（`ds1302.c` / `.h` 为截图，见飞书）

### 超声波

一发一收，时间乘声速得距离。发送 8 个 40 kHz 方波。\(f=40000\,\mathrm{Hz}\)，\(T=25\,\mu\mathrm{s}\)，高低电平各 12.5 μs。
