这条路线写给当时的自己，也留给后来的人。

## 打好 C 语言基础

C 语言是学 51 单片机的前提，但不用学到精通，**掌握到指针之前**就可以开始学单片机了。

1. 在 B 站搜索“西风”，跟完对应的 C 语言课程。
2. 学习时对照我的 [C 语言学习笔记](/blog/c-language-notes/)查缺补漏。
3. 实在卡住了再找其他讲解，别在语法细节上耗太久。

## 备战蓝桥杯单片机组

学完 C 语言，就可以开始备赛了。

1. 继续跟西风的课程，从零基础入门学到**串口通信**。
2. 每节课的笔记都在[蓝桥杯单片机课程笔记](/blog/mcu-notes/)里。
3. 老模板用熟以后，再学 **V4T 新模板**。这部分没有视频课，可以看文字教程，不懂的地方问 AI。
4. 刷历年真题，并上传 4T 测评。没拿到满分时，把自己的代码和满分代码一起交给 Codex 或 Claude Code，让它帮忙对照修改。
