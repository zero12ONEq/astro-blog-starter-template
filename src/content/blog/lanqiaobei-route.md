这是我给自己（也给后来者）整理的备赛路线，原文来自学习规划文档，迁到博客后略作排版。

## 1. C 语言基础

C 语言是 51 单片机的前置基础，但也不用精通——**掌握到指针之前**就够开始单片机。

建议路径：

1. B 站搜索「西风」，跟完对应 C 语言课程。
2. 学习时用我的 [C 语言学习笔记](/blog/c-language-notes/) 查缺补漏。
3. 实在卡住再找补充讲解，不要卡死在语法细节上。

## 2. 蓝桥杯单片机备赛

学完 C 就进入单片机组备赛。

1. 继续跟 B 站西风课程：从零基础入门学到**串口通讯**。
2. 每节课对应笔记见 [蓝桥杯单片机笔记](/blog/mcu-notes/)（从飞书迁入）。
3. 老模板熟练后，再学 **V4T 新模板**（文字教程 + AI 答疑）。
4. 刷历年真题，上传 4T 测评；对照满分代码，用 Codex / Claude Code 辅助对照修改。
